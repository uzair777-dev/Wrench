# dev/

Planning and working materials for Wrench — not shipped with the app, not imported by anything in `src/`.

- **`planning/`** — the SRS (`srs.md`) and implementation plan (`implementation-plan.md`) this project is built from. Tracked in git deliberately: they're the record of *why* decisions were made, not just *what* got built. Picking this project up for the first time? Start at `dev/planning/implementation-plan.md` §0, "How to Execute This Plan."
- **`scratch/`** — gitignored on purpose. Personal notes, throwaway sketches, anything not meant to be public or permanent. Don't assume anything here survives a fresh clone.
